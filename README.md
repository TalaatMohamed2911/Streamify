# streamify

Discover a new world of entertainment with streamify. Stream your live content seamlessly with crystal-clear quality.

## Getting Started

This is a Flutter application. Use the Gradle wrapper in `android/` rather than
installing a separate Gradle version. The Android build supports Java 24; the
Android thermal plugin is configured to use that compiler while targeting Java 17
bytecode for Android compatibility.

To build and run the Android app:

```sh
flutter pub get
flutter run
```
